## Intent
The README hero image (and GitHub Pages, if the project builds one) carries a
visual identity of "gravity magick": crude yet mystical bent field lines and
object trajectories emblazoned in stone, in the spirit of General Radahn's
sword. The favoured motif is a figure making a gravity-assist flyby (GFOB)
around a celestial body, carved into the stone — tying the art to the name,
since a periapsis is an orbit's closest approach and gravity assists happen
there.

Boundaries: Radahn's sword is a style reference only. No game art is copied or
traced.

## Acceptance criteria
- **AC-1** `necessary` `asserted` — The project owner approves the hero artwork.
  - Signers: project owner.
- **AC-2** `necessary` `empirical` — Every image used is original or licensed for this repository, with its source and licence recorded next to the asset.
- **AC-3** `supporting` `judged` — Rubric, fixed before review: reads as carved stone; shows bent field lines or trajectories; shows an orbit or flyby figure; is legible at README width. At least 2 of 3 non-author reviewers score it 4 or more out of 5.
  - Quorum: 2 of 3.
- **AC-4** `supporting` `empirical` — The hero renders legibly in both GitHub light and dark themes.

## Rationale
- The owner stated this branding intent in the original README.
- It is also a deliberately non-formal intent, so the Book exercises the
  `asserted`, `judged` and `empirical` modalities of INT-0002 on a real target.
- Sources: the root README as of commit `da806b1`.

## Alternatives
- **A generic logo or wordmark.** Loses the orbital theme the name was chosen
  for.

## Consequences
- Producing the art is human or commissioned work; agents can draft concepts,
  but only the owner can satisfy AC-1.
