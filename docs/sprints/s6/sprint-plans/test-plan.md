# Sprint 6 Test Plan

How to read the names:
- A test marked **new** is written by the task named.
- A test marked **renamed** keeps its assertions under a new name, except the assertions this plan lists as changed.
- A name starting **review** is a check a person or the code review makes against a recorded artefact, where no test can make it. Each says what is compared with what.
- Every other test exists at `b0675f6` and must still pass. Where one loses or changes an assertion, this plan says so.
